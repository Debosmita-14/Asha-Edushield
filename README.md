# ASHA EduShield 2.0

ASHA EduShield 2.0 is a campus safety and wellbeing demo experience for students, faculty, security staff, and administrators.

## Highlights
- SOS and incident workflow simulation
- Women safety and safe travel modules
- Wellness chat and campus analytics
- Responsive dashboard experience

## Run locally
Open index.html in a browser to explore the demo experience.
